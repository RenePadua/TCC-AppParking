# 💻📱AppParking - Web App de Estacionamento

## Web App utilizando PHP e SQL - Projeto de Trabalho de Conclusão de Curso

Neste web app são realizadas diversas etapas de um estacionamento como o registro de ingresso e saída de veículos, cálculo de cobrança do valor etc.
